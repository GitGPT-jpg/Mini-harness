# 恢复闭环覆盖矩阵

编号对应本轮五项修复执行要求。通过表示下述范围已有实际测试证据，不代表所有平台、模型和远端执行器都已验证。最终工程检查和原始产物路径见 [执行记录](loop-recovery-fixes-verification.md)。

## 覆盖层级

源码核验、Vitest、本地多进程竞争、SIGKILL/SIGSTOP、生产 HTTP 路由和真实 Chrome 输入路径均已执行。独立宿主 fixture 使用生产服务类和扩展，但替换模型/会话传输；不能称为完整真实模型运行。实际 `server/index` 浏览器恢复停止结果在执行记录中单独列示。

未运行真实模型、生产集群、多宿主、NFS 或 Linux 实机验收。Windows 与列明的不支持文件系统明确受阻；主动逃逸进程组的程序不在取消保证内。

R07/R08/R10/I06/I07 的“部分”表示仍有未执行的专项组合，不能用全量 Vitest 通过代替这些组合。动态 shell 可能加载静态分析无法识别的忽略目录文件，需用现有 `inputs.validatorPath/configPath` 等显式声明；本轮不声称推断任意动态依赖。
